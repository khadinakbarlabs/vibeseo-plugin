Exact full revisions, observed API metadata and inspected file paths are in [research](research/). The source files inspected were the relevant content-strategy, content-brief, keyword, backlink and README materials. VibeSEO's package text, contracts and templates were authored for this owner's Actor-backed workflow; it does not redistribute these projects' source files or executable components. No upstream install scripts, servers, agents, tracking, promotional footers or credentials are included. Their licenses govern those upstream projects. Conceptual research and attribution do not imply endorsement or affiliation.

Deliberate adaptations: missing data is reported, never silently skipped; advertising competition is separated from organic difficulty; no-contact/no-placement states stay explicit; saved context is in a visible chosen folder; billable and consequential operations require current approval; actual forums, video and other SERP formats are retained when they explain intent. Publisher self-promotion isn't appended to user reports.
