# Support

For package questions or defects, use the repository's GitHub Issues at https://github.com/khadinakbarlabs/vibeseo-plugin/issues. Include the plugin version, host/surface, affected skill, expected result, and a short redacted reproduction. Report a dependency/Actor failure with its public Actor name and a redacted error category.

Never post tokens, provider passwords, credential files, private run URLs, customer records or full logs in a public issue. For Apify account, login, retention or billing questions, use [Apify support](https://apify.com/contact). VibeSEO does not change account access, credits or plans.

Support is provided by the repository maintainer as available; no response-time guarantee is made. Directory review and publication are controlled by Anthropic.
